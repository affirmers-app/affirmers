# Affirmers roadmap

The roadmap is ordered by dependency, not by calendar. A phase starts when the previous one is finished and verified. Nothing here is a commitment to a delivery window.

## Phase 1: Foundation

- Public site with live Solana readings: slot ticker, chain health, TVL and a pair board
- A 90-second YES/NO call that lets visitors rehearse the backing instinct with invented profiles
- Source-of-truth register for every external fact, with inert placeholders until each is stated
- Build and verification gates that prove both branches of every gated element
- Design documents: whitepaper, tokenomics, architecture

Exit: the site is deployed, the register is complete, and all gates pass.

## Phase 2: Publication

- State and publish the contract address; the address slot at the top of the site goes live
- Publish the social account and the source repository link; their icons go live
- Independent review of the on-chain programs before any value moves through them

Exit: addresses and links are stated, review findings are resolved.

## Phase 3: Closed pilot

- Coin creation tied to verified handles, with small caps
- Vault routing and reward release on mainnet for a small group of backers
- Collect behaviour data: participation, concentration, claim rates

Exit: rewards release correctly across every path without manual intervention.

## Phase 4: Open access

- Remove pilot caps in steps, each gated on observed behaviour
- Discovery surfaces: people, activity and pools of support
- Tooling for people to claim and manage their own coin

## Phase 5: Refinement

- Settle the open parameters listed in `tokenomics.md`, each in public with reasoning
- Anti-abuse tuning from real data
- Integrations that let more social activity count toward rewards

## Not planned

Custody of user wallets, and any feature that promises a return.
